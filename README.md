# Pepsi Landing Page

A modern, responsive landing page for Pepsi, featuring a bold hero section, interactive can selector, and a mobile-friendly hamburger menu.

## Features
- Responsive design for desktop, tablet, and mobile
- Animated hamburger menu for navigation on small screens
- Interactive can images to change the hero product and background
- Clean, energetic branding and layout

## Folder Structure
```
pepsi/
  assets/
    css/
      all.min.css
      style.css
    img/
      logo.png
      p1.png
      p2.png
      p3.png
    js/
      all.min.js
      script.js
  index.html
```

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. No build tools or server required—just static files!

## Customization
- Edit `assets/css/style.css` for styles and responsiveness.
- Update `assets/js/script.js` for interactivity.
- Replace images in `assets/img/` as needed.
